---
name: Admissions consent scope
description: Optional VSL consent, separate counselling permission, and opt-out precedence.
---

VSL access must never require WhatsApp admissions-follow-up consent. Keep that
optional permission independent from question-29 counselling/appointment consent;
do not broaden the older permission into admissions follow-up.

An unchecked default on a return visit means no new grant, not an explicit
withdrawal of an earlier grant. An explicit recorded opt-out overrides both scoped
permissions and must not be cleared by registering again, checking a box again,
or submitting the questionnaire.

**Why:** The user requires optional consent, preserved opt-outs and recognition
of existing question-29 consent without changing the questionnaire's behavior.

**How to apply:** Check current scoped permission and opt-out state before any
future outreach. Registration/webhook receipt is not permission to send messages.
Future re-opt-in and external opt-out ingestion require explicit, auditable flows.
